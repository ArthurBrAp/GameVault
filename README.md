# 🎮 GameVault

O GameVault é um projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

O projeto simula uma loja de jogos e foi criado para colocar em prática meus conhecimentos de Python, SQL e banco de dados MySQL.

## 📌 Funcionalidades

- Cadastro de clientes
- Cadastro de jogos
- Listagem de jogos
- Carrinho de compras
- Registro de vendas
- Registro dos itens de cada venda
- Escolha da forma de pagamento

## 🛠️ Tecnologias utilizadas

- Python
- MySQL
- SQL
- MySQL Connector/Python

## 🗄️ Banco de Dados

O banco de dados foi desenvolvido no MySQL e possui tabelas para armazenar informações de:

- Clientes
- Jogos
- Vendas
- Itens das vendas
- Formas de pagamento
- Pagamentos

O arquivo `gamevault.sql` com a estrutura do banco está disponível neste repositório.

## 🎯 Objetivo do projeto

O principal objetivo do GameVault foi praticar a integração entre Python e MySQL, além de desenvolver conhecimentos em lógica de programação, SQL e modelagem de banco de dados.

## 📚 Contexto

Projeto desenvolvido para fins acadêmicos e de aprendizado durante a graduação em Análise e Desenvolvimento de Sistemas.
